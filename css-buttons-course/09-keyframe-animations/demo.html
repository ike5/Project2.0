Module 09 — Keyframe Animations

Self-running motion with @keyframes: pulse, shimmer, spinner, shake, and a self-drawing success check. Everything here animates with no JavaScript. Turn on your OS "reduce motion" setting and reload to see it all calm down.

1 · Pulsing CTA — "look at me"

A scale loop layered with an expanding box-shadow ring (two comma-separated animations) draws the eye without shouting. Loops forever via infinite.

2 · Shimmer / skeleton loading

A gradient wider than the box (background-size: 200%) whose background-position slides a highlight across it. The universal "content is loading" placeholder.

3 · Spinner inside a loading button

A circle with three visible border sides and one transparent (border-top-color bright), spun 360deg linear infinite. linear keeps the spin perfectly even.

4 · Shake on error (runs once)

A quick left-right translateX jitter that fires once — hover to retrigger it here; in an app you'd add the class after a failed action. Small travel, fast, never looping.

5 · Success — a self-drawing check

An inline SVG path animated via stroke-dasharray + stroke-dashoffset, held with fill-mode: forwards. It draws on load; hover to watch it draw again.

6 · Pause a loop on hover (play-state)

Pure-CSS control: the button pulses until you hover, then animation-play-state: paused freezes it in place — no reset, no JS.

7 · Layering multiple animations

Two independent timelines on one element — a slow float and a faster glow — running on their own clocks via a comma-separated animation list.

View source to read the CSS — the lesson styles are in the block marked THE ACTUAL LESSON CSS. Every looping effect is disabled or reduced under @media (prefers-reduced-motion: reduce).
