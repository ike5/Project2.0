Module 15 — Capstone: A Button Design System

One tokenized .btn base plus BEM modifiers = every button below. Tab through them to see the keyboard-only :focus-visible ring. This gallery inlines solutions/buttons.css so it runs from file://.

1 · Variants

Emphasis, encoded. Each is .btn + one modifier that repaints only background/color and reads from role tokens.

2 · Sizes

A size modifier changes only --btn-font; em-based padding scales the rest. Same rule, proportional results.

3 · Shapes

Pill (999px), plus square and round icon-only buttons. Icon-only buttons carry an aria-label — no visible text to announce.

4 · Icons + labels

Icon support is built into the base via gap. An inline SVG (or emoji) is just the first flex child; mark decorative icons aria-hidden.

5 · States

Every state is driven by a real attribute, so it's both shown and announced. Loading uses aria-busy and keeps the button's width — no reflow. The spin stops under reduced-motion.

6 · Both themes, no JavaScript

The same markup twice. The left panel forces [data-theme="light"]; the right forces [data-theme="dark"]. Only the tokens change — the rules are identical.
