Module 07 — Transitions & Timing Functions

The journey between states. Hover, press, and race the easings below — motion is guarded by prefers-reduced-motion, so it quiets if your OS asks.

1 · The shorthand — one property, one curve

transition: background-color 150ms ease on the base rule. The color now glides instead of snapping. It lives on the base rule so it animates both into and out of the hover.

2 · Race the five built-in easings

Identical buttons, identical distance, identical 600ms duration — only the timing-function differs. Hover one lane to launch it, or hover the whole track to launch all five and watch them separate. linear is mechanical; ease-out arrives gently; ease-in yanks away.

3 · The hover-lift — transform + shadow

Rises on hover via transform: translateY(-4px) (composited, smooth) while the shadow grows to sell the height. Never animate top for this — transform stays buttery. Press it to feel it push back down. (Perf tease → Module 14.)

4 · Multiple properties, different durations — vs. the all trap

Left: an explicit comma list — background snaps in 140ms while the lift & shadow take 280ms. Right: transition: all — it also animates the hover border nobody meant to animate, so the edge jumps. Name your properties.

5 · Staggering with delay

The arrow moves first; the label follows 90ms later via transition-delay. Same motion, but the small offset reads as choreographed.

6 · Asymmetric in vs. out

Snaps up crisply on hover (130ms ease-out, set on :hover) and settles back slowly (300ms ease-in, set on the base rule). In ≠ out — the subtle asymmetry that reads as premium. Hover on, then off, slowly.
