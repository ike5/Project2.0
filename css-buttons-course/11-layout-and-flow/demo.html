Module 11 — Layout & Flow

A button is a flex container — inside (icon + label) and out (groups, split buttons, toolbars). Try tabbing through, and resize the window to watch the toolbar and button rows wrap.

1 · Icon + label — leading & trailing

display: inline-flex + gap spaces the icon from the text. Leading vs. trailing is just source order. Every icon is aria-hidden; the label carries the meaning.

2 · Icon-only buttons — square & circle

No text, so each one must carry an aria-label. Equal width/height + padding: 0 make the box; border-radius: 50% makes it round. The inherited centering drops the icon dead-center.

3 · Label truncation inside flex

The icon and count stay fixed (flex: none); only the .label clips with …. It works only because the label has min-width: 0 — remove it and the text bulldozes the button.

4 · Segmented control / button group

A flex row with no gap: buttons share edges. Only the outer corners are rounded (:first-child/:last-child), and margin-left: -1px collapses the doubled border into one seam. Click to toggle aria-pressed.

5 · Split button

A wide primary action plus a narrow caret segment that opens more options. The caret is an icon-only button — real aria-label + aria-haspopup. The divider is an inset box-shadow, so it adds no width.

6 · Toolbar — wrap-friendly

A flex row with gap and flex-wrap: wrap: it never overflows, it wraps. margin-left: auto on the last button pushes it to the far end. Narrow your window to see it stack.

7 · Full-width & responsive

width: 100% + display: flex gives a block CTA; justify-content: space-between shoves the label left and the chevron to the right edge. Below, flex: 1 1 auto lets a button row share space and wrap with no media query.

8 · Badges & counters

Two techniques. Inline pill: a normal flex child after the label. Floating badge: position: absolute pinned to a corner, anchored by position: relative on the button. The number gets an aria-label so it reads as meaningful.
