Module 02 — Typography, Color & Contrast

Labels that read well, a semantic color system in custom properties, states derived from one base color, and contrast you can trust. Tab through with your keyboard to see :focus-visible.

1 · Semantic variant set

Five roles, each a single class that just points --base at a different token in :root. Primary / secondary / success / danger / warning — intent, not hex.

2 · Hover / active auto-derived from one base (color-mix)

No hand-picked hover colors. color-mix(in srgb, var(--base) 88%, black) darkens whatever the base is — so every variant gets correct states from one rule. Hover and press these.

3 · Same idea in HSL — lower the lightness

Store the color as H S L channels and just drop L for hover/active. Dependency-free shade math.

→ hover L 50% → active L 42%

4 · Soft / tinted variants (mix toward transparent)

A translucent wash of the same hue with colored text — great for a secondary emphasis. color-mix(in srgb, var(--base) 15%, transparent).

5 · Uppercase & letter-spaced label style

Caps require tracking or they read as a wall. Note the optical fix: letter-spacing: .09em, font-weight: 700, and font-size: .82em so the caps don't look oversized.

6 · Truncated long label (nowrap + ellipsis)

Capped at 15ch. The label truncates with … instead of wrapping or overflowing. The full text lives in a title so nothing is lost. (Hover to see it.)

7 · Contrast: GOOD vs BAD

Same amber fill. White text fails hard (~1.9:1); near-black passes (~10:1). Light, saturated colors want dark text — don't default to white. WCAG minimum for normal text is 4.5:1.

✕ ~1.9:1 FAIL
✓ ~10:1 PASS

Don't rely on color alone: pair the hue with a word or icon (🗑 Delete, ✓ Save) so meaning survives color-blindness.

8 · Translucent fills — three equivalent recipes

Alpha makes only the background see-through (text stays crisp), unlike opacity which fades everything. The checkerboard shows through all three identical 18% blue tints.

rgba(… / .18) hsl(… / .18) color-mix →transparent
