Module 08 — Bézier Curves & Custom Easing

Every demo below is driven by a cubic-bezier(), steps(), or linear() token. Hover (or tab into) each to feel the curve. The curve is the character of the motion — same distance, different soul.

1 · Same move, four curves — watch the overshoot

Each runner travels the exact same distance in the exact same time. Only the timing function differs. linear arrives coldly; ease-out decelerates; easeOutBack flies past and springs back; easeOutExpo rushes then glides. Hover a lane (or tab to a runner).

2 · Overshoot (y>1) vs. anticipation (y<0)

Hover each stage. Left uses easeOutBack — it pops up past its target and settles (follow-through). Right uses an anticipate curve — it dips down first (a wind-up) before launching. Both are a single Bézier; the personality is entirely in the Y values.

5 · linear() — a true multi-bounce

A single cubic-bezier() can cross its target only once, so it can't really bounce. The modern linear() function traces any shape from a list of progress stops. Hover to drop the ball — it bounces, then settles. (Falls back to a single overshoot on browsers without linear().)
