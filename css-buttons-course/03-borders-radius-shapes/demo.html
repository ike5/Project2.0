Module 03 — Borders, Radius & Shapes

The shape layer: edges, rounding, pills, circles, and custom clip-path shapes. Tab through the buttons to see focus rings survive even on clipped shapes.

1 · Border vs. outline

A border is part of the box and takes up space. An outline is painted on top and reserves none — which is why it's the right tool for a focus ring. The cyan ring below sits outside the box via outline-offset.

2 · The rounding scale (0 → pill)

One property, border-radius, from square to fully rounded. The last one asks for 999px and the browser clamps it to a pill.

3 · The pill — clamps at any width

All three use the same border-radius: 999px. The radius clamps to half the height, so the ends stay perfect semicircles no matter how long the label is.

4 · Circular icon buttons

A square box + border-radius: 50%. Left group uses fixed width/height; right uses aspect-ratio: 1. Every one has an aria-label because there's no visible text.

5 · Ghost / outline buttons

Transparent fill, border: 2px solid currentColor (the border matches the text). The border is present at rest, so hover fills the button with no layout jump. First fills solid; second uses a soft tint.

6 · Cut / beveled corners

Two corners sliced off with clip-path: polygon(). Mixing px and % via calc() keeps the bevel a fixed size at any width. The focus ring still shows — outline is drawn outside the clip.

7 · Custom shapes — arrow, tag, ticket

All pure clip-path. The ticket adds a punched hole with a ::before pseudo-element and notches on both edges. A true gradient border (the pink one below is just teased) arrives in Module 12.

8 · Per-corner radius playground

Click a preset to reshape the button — no JavaScript, just :checked radios and sibling selectors. Each preset feeds border-radius in CSS order: top-left, top-right, bottom-right, bottom-left. Tab to a chip and press arrow keys to cycle.
