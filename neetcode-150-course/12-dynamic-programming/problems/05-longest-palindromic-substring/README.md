# Longest Palindromic Substring

**Difficulty:** Medium

## Problem

Given a string `s`, return the longest palindromic substring.

## Examples

```
Input:  s = 'babad'
Output: 'bab' or 'aba'
```

```
Input:  s = 'cbbd'
Output: 'bb'
```

## Constraints

- 1 <= len(s) <= 1000
- s consist of only digits and English letters

## Hints

1. Expand around each center. A palindrome has 2n-1 possible centers (between or on characters).
