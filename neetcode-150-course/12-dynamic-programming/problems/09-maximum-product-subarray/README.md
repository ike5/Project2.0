# Maximum Product Subarray

**Difficulty:** Medium

## Problem

Given an integer array `nums`, find a subarray that has the largest product, and return the product.

## Examples

```
Input:  nums = [2,3,-2,4]
Output: 6
```

```
Input:  nums = [-2,0,-1]
Output: 0
```

## Constraints

- 1 <= len(nums) <= 2 * 10^4
- -10 <= nums[i] <= 10

## Hints

1. Track both max and min products: a negative flips them.
