**You'll:** build the LFU Cache from the README, then run the full LeetCode 460 example as a test. ⏱️ ~45 min.

---

## Part A — Implement and run

```bash
python 12-capstone/code/lfu_cache.py
```

✅ You should see the trace of LeetCode 460's example.

## Part B — Stress test

```bash
python 12-capstone/code/lfu_stress.py
```

✅ The stress test compares your LFU to a naive reference for thousands of random operations. If it passes, your solution is correct on the random cases.

## Part C — pytest

```bash
python -m pytest 12-capstone/code/test_lfu_cache.py
```

✅ All tests pass.

## Part D — Submit to LeetCode

Open [460. LFU Cache](https://leetcode.com/problems/lfu-cache/) and submit. It should pass.
